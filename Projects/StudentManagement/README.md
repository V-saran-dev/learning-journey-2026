# Student Management System

## Overview

The Student Management System is a console-based Java application designed to manage basic student records efficiently. It allows users to add, view, search, and delete student information through a simple menu-driven interface.

## Features

- Add a new student
- View all registered students
- Search for a student using their ID
- Delete a student record
- Interactive menu-driven interface
- Uses object-oriented programming concepts
- Stores student records using Java ArrayList

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- VS Code
